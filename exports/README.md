# ข้อสอบทั้งหมด → Excel / CSV

ส่งออกข้อสอบทุกข้อจากคลังใน `src/data/*.js` (ข้อมูลชุดเดียวกับที่เว็บใช้) เป็นไฟล์ตาราง
ตามโครงสร้างที่กำหนด:

| คอลัมน์ | ความหมาย |
| --- | --- |
| `question` | โจทย์ |
| `option1` – `option4` | ตัวเลือกที่ 1–4 ตามลำดับจริง |
| `correct` | หมายเลขตัวเลือกที่ถูก **1–4** (1 = option1) |
| `time_limit` | 10 (วินาที/ข้อ) |
| `points` | คะแนนต่อข้อ — พาร์ทหลัก 1 · ข้อสอบพิเศษ = คะแนนทั้งชุด ÷ จำนวนข้อ |
| `หมวด` | ชั้นของข้อสอบ (1 / 2 / 3 / ข้อสอบพิเศษ) |
| `วิชาย่อย` | หัวข้อย่อยของข้อนั้น |

## ใช้งาน

```bash
python3 tools/export_questions.py
```

ต้องมี `node` (อ่านคลังข้อสอบ) และ `openpyxl` + `pillow` (`pip install openpyxl pillow`)

ผลลัพธ์ในโฟลเดอร์ `exports/`

- `BACC2569_ข้อสอบทั้งหมด.xlsx` — ไฟล์หลัก
  - **ข้อสอบทั้งหมด** — 1,490 แถว × 10 คอลัมน์ตามโครงสร้าง (นำเข้าได้ทันที)
  - **สรุปจำนวนข้อ** — จำนวนข้อ/เวลา/คะแนน/จำนวนข้อที่ใช้ภาพของแต่ละพาร์ท
  - **คำอธิบายเฉลย** — เฉลย + คำอธิบายรายข้อ
  - **ข้อที่เป็นภาพ** — 147 ข้อที่ต้องดูภาพ ฝังภาพจริง 342 ภาพ พร้อม path ต้นฉบับใน `public/`
  - **ข้อที่ต้องตรวจ** — จุดที่ควรตรวจด้วยมือ
  - **อ่านก่อนใช้งาน** — คำอธิบายไฟล์
- `BACC2569_ข้อสอบทั้งหมด.csv` — 10 คอลัมน์เดียวกัน (UTF-8 BOM เปิดใน Excel ได้ตรง)
- `แยกตามพาร์ท/*.csv` — 17 ไฟล์ แยกตามพาร์ท/ชุด สำหรับนำเข้าทีละวิชา

## หมายเหตุข้อมูล

- ข้อที่โจทย์หรือตัวเลือกเป็นภาพ จะขึ้น `[ภาพ]`, `[ภาพ 1]`… หรือ
  `[ดูตัวเลือกในภาพโจทย์]` ในช่องนั้น และดูภาพจริงได้ในชีต “ข้อที่เป็นภาพ”
- ชุด Mock Exam 30 ข้อ ไม่ถูกรวม เพราะเป็นข้อที่หยิบมาจากพาร์ทหลักซ้ำ
- ตัวเลขสรุป: พาร์ทหลัก 11 พาร์ท × 100 = 1,100 ข้อ + ข้อสอบพิเศษ 6 ชุด = 390 ข้อ
