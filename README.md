# BACC Exam 2569 — เว็บไซต์ทดสอบออนไลน์ ธ.ก.ส.

เว็บแอปภาษาไทยสำหรับ **ฝึกทำข้อสอบพนักงานการเงิน ระดับ 4 ธ.ก.ส. ปีบัญชี 2569**
แยกตามพาร์ท สร้างชุดสอบเสมือนจริงได้เองตามโครงสร้างประกาศ อ่านเอกสารต้นฉบับได้ในหน้าเว็บ
หยุดพักแล้วกลับมาทำต่อได้ พร้อมดาวน์โหลดผลการทดสอบและชุดข้อสอบเป็น PDF

## คุณสมบัติ

### ผู้เข้าทดสอบและประวัติ
- **ระบุชื่อครั้งแรก** — ครั้งแรกที่เข้าใช้งานระบบจะถามชื่อ–นามสกุล แล้วจดจำไว้ให้อัตโนมัติ
  ในครั้งถัดไป
- **หลายคนในเครื่องเดียว** — สลับ/เพิ่ม/เปลี่ยนชื่อ/ลบผู้เข้าทดสอบได้ ประวัติแต่ละคนแยกกันโดยสมบูรณ์
- **ประวัติถาวร** — ผลสอบทุกครั้งเก็บใน `localStorage` ของเครื่อง (ไม่มีการส่งข้อมูลออก)
  กรองดูได้ทั้งแบบแยกพาร์ทและชุดข้อสอบ และลบรายรายการได้

### ข้อสอบและตัวจับเวลา
- **11 พาร์ทสอบ + Mock Exam** — 1.1 คณิตศาสตร์ · 1.2 วิเคราะห์และเหตุผล · 1.3 ภาษาไทย ·
  1.4 มิติสัมพันธ์ · 1.5 ภาษาอังกฤษ · 2 ความละเอียดแม่นยำ · 3.1 หลักการบัญชี ·
  3.2 การเงินการธนาคาร · 3.3 เศรษฐศาสตร์ · 3.4 สินเชื่อและพัฒนาชนบท · 3.5 การตลาด
- **จับเวลาแยกแต่ละพาร์ท/รายวิชา** และนับสะสมต่อเนื่อง — กด “หยุดพัก” ได้ทุกเมื่อ
  คำตอบ เวลาที่ใช้ และข้อที่ทำค้างไว้จะถูกบันทึก กลับมาทำต่อได้แม้ปิดเบราว์เซอร์
  (มีการ์ด “ทำค้างไว้ · ทยอยทำต่อ” บนหน้าแรก)
- ส่งคำตอบอัตโนมัติเมื่อหมดเวลา, ปักธงข้อที่สงสัย, แผงรายการข้อสอบแยกตามรายวิชา

### ระบบสร้างข้อสอบ (Exam generator)
- สุ่มชุดใหม่ตาม **โครงสร้างข้อสอบจริง**

  | รายวิชา | จำนวนข้อ | คะแนน |
  | --- | --- | --- |
  | 7.1.1 ความรู้ความสามารถทั่วไป | 80 | 100 |
  | 7.1.2 ความละเอียดแม่นยำ | 50 | 50 |
  | 7.1.3 ความรู้เฉพาะตำแหน่ง | 100 | 100 |
  | **รวม** | **230** | **250** |

  เลือกได้ระหว่าง “ชุดตามประกาศทางการ” (230 ข้อ / 250 คะแนน / 240 นาที)
  และ “ชุดย่อซ้อมเร็ว” (60 ข้อ / 65 คะแนน / 60 นาที)
- ข้อสอบมาจาก 3 แหล่งรวมกัน: คลังที่เรียบเรียงไว้ 118 ข้อ + เทมเพลตคำนวณ/ความละเอียด
  ที่สร้างใหม่ทุกครั้ง + คลังข้อสอบเสริมเชิงเนื้อหาในแต่ละวิชา ทำให้ชุด 230 ข้อ
  **ไม่มีข้อซ้ำ** และไม่ซ้ำในชุดเดียวกัน
- **รหัสชุด (seed)** กำหนดผลลัพธ์แบบ deterministic — รหัสเดียวกันได้ชุดเดิมเสมอ
- ทุกชุดได้ชื่ออัตโนมัติว่า “ชุดสอบเสมือนจริง ชุดที่ N” และแก้ชื่อได้

### แชร์ชุดข้อสอบ + Export PDF
- **รหัสแชร์** (ข้อความสั้น) — ส่งให้เพื่อนแล้วนำเข้าที่ช่อง “รับชุดข้อสอบจากเพื่อน”
  ระบบสร้างชุดเดียวกันให้ทำ แต่ **ประวัติการทำแยกตามชื่อผู้เข้าทดสอบ**
- **Export PDF ของทั้งชุด** — ปกหน้า + โครงสร้างชุด + ข้อสอบทุกข้อ (ตัวเลือก 4 ข้อ)
  + เฉลยท้ายเล่ม (เปิด/ปิดได้) พิมพ์หรือเก็บไว้อ่านได้

### เอกสารต้นฉบับ + ธีม
- **อ่านเอกสารในเว็บไซต์** — เปิด PDF จาก Google Drive ในกรอบอ่านของเว็บ (embedded preview)
  พร้อมปุ่มดาวน์โหลด/เปิดต้นฉบับสำรอง
- **โหมดมืด / โหมดสว่าง** — สลับได้จากหัวเว็บหรือหน้าบัญชี และจำค่าไว้
- ลูกเล่น: blob ลอย, fade-up แบบ stagger, progress ring, shimmer, confetti, bottom sheet,
  การ์ดไล่สี, แถบความคืบหน้ารายวิชา


```
    Result.jsx          # ผลคะแนน + สรุปรายวิชา + เฉลย + ดาวน์โหลด

    ExamBuilder.jsx     # สร้างชุด · แชร์ · นำเข้า · export PDF
    DocReader.jsx       # ตัวอ่านเอกสารในหน้าเว็บ
    Sources.jsx         # รายการเอกสารต้นฉบับ
    ui.jsx, Icons.jsx   # UI primitives / ไอคอน SVG
  data/
    set1.js set2.js set3.js  # คลังข้อสอบที่เรียบเรียงไว้ (118 ข้อ)
    index.js                 # metadata พาร์ท + ไฟล์ Drive + Mock Exam
  lib/
    generator.js        # สร้างชุดข้อสอบ 80/50/100 จาก seed (deterministic)
```

## การเก็บข้อมูล (localStorage)

| key | เก็บอะไร |
| --- | --- |
| `bacc2569:profiles` | รายชื่อผู้เข้าทดสอบ |
| `bacc2569:current` | ผู้ใช้ที่กำลังใช้งาน |
| `bacc2569:results:<id>` | ผลสอบของแต่ละคน (แยกกัน) |
| `bacc2569:attempts:<id>` | ข้อสอบที่ทำค้างไว้ + เวลาสะสม |
| `bacc2569:sets` | ชุดข้อสอบที่สร้าง/รับมา (ใช้ร่วมกันในเครื่อง) |
| `bacc2569:theme` | `light` / `dark` |

ข้อมูลเดิมจากเวอร์ชันแรก (`bacc-exam-2569/*`) จะถูกย้ายเข้าสู่ระบบโปรไฟล์อัตโนมัติ
