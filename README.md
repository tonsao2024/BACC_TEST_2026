เว็บแอปภาษาไทยสำหรับ **ฝึกทำข้อสอบพนักงานการเงิน ระดับ 4 ธ.ก.ส. ปีบัญชี 2569**

## คุณสมบัติ

### ผู้เข้าทดสอบและประวัติ
- **ระบุชื่อครั้งแรก** — ครั้งแรกที่เข้าใช้งานระบบจะถามชื่อ–นามสกุล แล้วจดจำไว้ให้อัตโนมัติ
  ในครั้งถัดไป
- **หลายคนในเครื่องเดียว** — สลับ/เพิ่ม/เปลี่ยนชื่อ/ลบผู้เข้าทดสอบได้ ประวัติแต่ละคนแยกกันโดยสมบูรณ์
- **ประวัติถาวร** — ผลสอบทุกครั้งถูกเก็บไว้ (ในเครื่อง + สำรองขึ้น GitHub เมื่อเชื่อมต่อ)
  กรองดูได้ทั้งแบบแยกพาร์ทและชุดข้อสอบ และลบรายรายการได้

### ข้อสอบและตัวจับเวลา
- **11 พาร์ทสอบ + Mock Exam** — 1.1 คณิตศาสตร์ · 1.2 วิเคราะห์และเหตุผล · 1.3 ภาษาไทย ·
  1.4 มิติสัมพันธ์ · 1.5 ภาษาอังกฤษ · 2 ความละเอียดแม่นยำ · 3.1 หลักการบัญชี ·
  3.2 การเงินการธนาคาร · 3.3 เศรษฐศาสตร์ · 3.4 สินเชื่อและพัฒนาชนบท · 3.5 การตลาด
- **จับเวลาแยกแต่ละพาร์ท/รายวิชา** และนับสะสมต่อเนื่อง — กด “หยุดพัก” ได้ทุกเมื่อ
  คำตอบ เวลาที่ใช้ และข้อที่ทำค้างไว้จะถูกบันทึก กลับมาทำต่อได้แม้ปิดเบราว์เซอร์
  (มีการ์ด “ทำค้างไว้ · ทยอยทำต่อ” บนหน้าแรก)
- **เฉลยทันที + คำอธิบายละเอียด** — เลือกตัวเลือกแล้วเห็นผลทันที ตัวเลือกที่ถูกไฮไลต์สีเขียว
  ตัวเลือกที่ผิดสั่นเบา ๆ พร้อมเฉลย คำอธิบายเชิงเนื้อหา และหัวข้อ/ระดับความยากของข้อนั้น
  (ปิดได้ในหน้าบัญชีหรือในแผงรายการข้อสอบ หากต้องการทำแบบไม่เห็นเฉลยจนส่ง)
- **เอฟเฟกต์ตอบคำถาม** — ไฮไลต์ตอนเลือก, วงแหวนเรืองแสงเมื่อตอบถูก, ประกายอนุภาคสี,
  สั่นเบา ๆ เมื่อตอบผิด, ตัวเลขในพาเลตต์เปลี่ยนสีตามผล
- **เดสก์ท็อป & มือถือ** — มือถือใช้แถบเมนูล่าง/การ์ดเต็มความกว้าง, จอ ≥ 1080px
  เปลี่ยนเป็นเลย์เอาต์ 2 คอลัมน์ มีเมนูด้านซ้าย และแผงภาพรวมข้อสอบ (พาเลตต์ + เวลารายวิชา) ติดขอบจอ
- ส่งคำตอบอัตโนมัติเมื่อหมดเวลา, ปักธงข้อที่สงสัย, แผงรายการข้อสอบแยกตามรายวิชา

### ระบบสร้างข้อสอบ (Exam generator)
- สุ่มชุดใหม่ตาม **โครงสร้างข้อสอบจริง**

  | รายวิชา | จำนวนข้อ | คะแนน |
  | --- | --- | --- |
  | 7.1.1 ความรู้ความสามารถทั่วไป | 80 | 100 |
  | 7.1.2 ความละเอียดแม่นยำ | 50 | 50 |
  | 7.1.3 ความรู้เฉพาะตำแหน่ง | 100 | 100 |
  | **รวม** | **230** | **250** |

  เลือกได้ระหว่าง “ชุดตามประกาศทางการ” (230 ข้อ / 250 คะแนน / 240 นาที)
  และ “ชุดย่อซ้อมเร็ว” (60 ข้อ / 65 คะแนน / 60 นาที)
- ข้อสอบมาจาก 3 แหล่งรวมกัน: คลังที่เรียบเรียงไว้ 118 ข้อ + เทมเพลตคำนวณ/ความละเอียด
  ที่สร้างใหม่ทุกครั้ง + คลังข้อสอบเสริมเชิงเนื้อหาในแต่ละวิชา ทำให้ชุด 230 ข้อ
  **ไม่มีข้อซ้ำ** และไม่ซ้ำในชุดเดียวกัน
- **รหัสชุด (seed)** กำหนดผลลัพธ์แบบ deterministic — รหัสเดียวกันได้ชุดเดิมเสมอ
- ทุกชุดได้ชื่ออัตโนมัติว่า “ชุดสอบเสมือนจริง ชุดที่ N” และแก้ชื่อได้
- **ชุดข้อสอบเก็บไว้ที่ไหน**
  - ในเครื่อง: `localStorage` key `bacc2569:sets` — เก็บ 40 ชุดล่าสุด
  - บน GitHub: อาร์เรย์ `sets` ในไฟล์ `bacc-data.json` (gist/repo) ซิงก์อัตโนมัติเมื่อเชื่อมต่อ
  - ไฟล์เก็บแค่ `seed` + `sizeKey` + ชื่อชุด (ไม่เก็บข้อสอบ 230 ข้อ) จึงเล็กมาก
    และสร้างชุดเดิมได้ตรงกันทุกครั้ง — ประวัติการทำแยกอยู่ใน `results` / `attempts` ต่อผู้ใช้
  - หน้าจอ “ชุดสอบ” และหน้าต่างหลังสร้างเสร็จ มีการ์ดอธิบายที่เก็บให้เห็นชัดเจน

### แชร์ชุดข้อสอบ + Export PDF
- **รหัสแชร์** (ข้อความสั้น) — ส่งให้เพื่อนแล้วนำเข้าที่ช่อง “รับชุดข้อสอบจากเพื่อน”
  ระบบสร้างชุดเดียวกันให้ทำ แต่ **ประวัติการทำแยกตามชื่อผู้เข้าทดสอบ**
- **Export PDF ของทั้งชุด** — ปกหน้า + โครงสร้างชุด + ข้อสอบทุกข้อ (ตัวเลือก 4 ข้อ)
  + เฉลยท้ายเล่ม (เปิด/ปิดได้) พิมพ์หรือเก็บไว้อ่านได้

### เอกสารต้นฉบับ (PDF เท่านั้น) + ธีม
- **อ่านเอกสารในเว็บไซต์** — รองรับเฉพาะไฟล์ **PDF** เปิดในกรอบอ่านของเว็บ (Drive PDF preview)
  มีรายการไฟล์ PDF ให้สลับด้านซ้าย, สถานะกำลังโหลด, แจ้งเตือนเมื่อโหลดช้า,
  ปุ่มดาวน์โหลด และปุ่มเปิดในแท็บใหม่
- ไฟล์ Markdown (สารบัญ/สรุป) จะแสดงข้อความอธิบายและปุ่มดาวน์โหลดแทนการฝังในเว็บ
- **โหมดมืด / โหมดสว่าง** — สลับได้จากหัวเว็บหรือหน้าบัญชี และจำค่าไว้ (โทนกรมท่า–น้ำเงินทั้งสองโหมด)
- **พาเลตต์สดใส โทนน้ำเงิน–กรมท่า** — `#2563EB` / `#0B1F3A` / `#38BDF8` / `#06B6D4`
  พร้อมสีประจำรายวิชาที่แยกกันชัดเจน
- **ตัวละครเคลื่อนไหว (mascot SVG)** — การ์ดพาร์ททุกใบมีตัวละครขยับได้ (เด้ง/กะพริบตา/โบกมือ)
  หน้าแรกมีมาสคอตคู่ลอยในฮีโร่ มีเอฟเฟกต์แสงกวาด ประกาย และการ์ดยกขึ้นเมื่อชี้
- ลูกเล่น: blob ลอย, fade-up แบบ stagger, progress ring, shimmer, confetti, bottom sheet,
  การ์ดไล่สี, แถบความคืบหน้ารายวิชา, การ์ดเฉลยแบบไดนามิก, ripple ตอนกดปุ่ม
- **สลับบัญชีได้ทันที** — ปุ่ม “ไม่ใช่ …? สลับบัญชี” ใต้ชื่อบนหน้าแรก และปุ่ม “สลับบัญชี”
  ในหน้าบัญชี (กรณีล็อกอินผิดคน)
- **แข่งขันกับเพื่อน** — ตารางอันดับจากคะแนนเฉลี่ยของทุกบัญชีในระบบ พร้อมปุ่ม
  “สร้างชุดแข่งให้เพื่อนทำ + คัดลอกรหัส” (ประวัติยังแยกตามผู้เข้าทดสอบ)
- **การแจ้งเตือน (toast)** — ตรึงเหนือแถบเมนู เข้ากับ safe-area ของ iPhone,
  จำกัดความกว้างไม่ให้ล้นจอ และย้ายไปมุมขวาล่างบนเดสก์ท็อป

### ฐานข้อมูล GitHub (แทน localStorage อย่างเดียว)
- เปิด **บัญชี → การตั้งค่า → คลังข้อมูล GitHub** แล้วเลือกโหมด
  - **Secret Gist · ง่ายสุด (ค่าเริ่มต้น)** — ใช้แค่ token ระบบสร้าง gist ส่วนตัวให้อัตโนมัติ
  - **Repository** — เก็บไฟล์ JSON ใน repo ของคุณเอง (มีปุ่ม “ดึงชื่อ” เติม owner จาก token)
- แผงจะแสดงชิป **“ข้อมูลที่จะบันทึก”** ให้เห็นจำนวนจริงก่อนกดเชื่อมต่อ:
  โปรไฟล์ · ประวัติผลสอบ · งานค้าง · ชุดข้อสอบ · การตั้งค่า (เฉลยทันที/ธีม)
- กด “ทดสอบการเชื่อมต่อ” ระบบจะเรียก `GET /repos/{owner}/{repo}` ให้เห็นผลก่อนบันทึก
- เมื่อเชื่อมต่อแล้ว
  - **ดึง + รวมข้อมูล** ตอนเปิดแอป: รวมโปรไฟล์ (ตาม `id`, ตัวใหม่สุดชนะ) และผลสอบ
    (ตาม `id`) / งานค้าง (ตาม `key` + `updatedAt`) แบบ union — ไม่มีข้อมูลฝั่งไหนหาย
  - **ผลักข้อมูลอัตโนมัติ** หลังมีการเปลี่ยนแปลง (หน่วง 1.5 วินาทีเพื่อรวมยอด) พร้อม
    จัดการ conflict `409` ด้วยการดึง sha ใหม่แล้วส่งซ้ำ
  - ปุ่ม “ซิงก์เดี๋ยวนี้” สำหรับสั่งด้วยมือ และสถานะบอกทุกขั้น (กำลังบันทึก / สำเร็จ / ผิดพลาด)
  - **ชิปสถานะบนหน้าแรก** — “บันทึกขึ้น GitHub แล้ว · เวลา” กดแล้วเปิดหน้าบัญชีได้ทันที
  - เปลี่ยน **การตั้งค่า/ธีม** อย่างเดียวก็ถูกผลักขึ้นอัตโนมัติ (ตรวจลายนิ้วมือข้อมูลก่อนส่ง
    เพื่อไม่ส่งซ้ำเมื่อข้อมูลไม่เปลี่ยน — มีเทสต์ยืนยัน)
- รูปแบบไฟล์ (`bacc-data.json`) คือ snapshot เดียวกับที่ใช้สำรองในเครื่อง
  `{ profiles, results, attempts, sets, settings, theme, updatedAt, ... }`
- **ความปลอดภัย** — token ไม่ถูกใส่ในไฟล์ที่อัปโหลด (ทดสอบยืนยันแล้ว) เก็บเฉพาะใน
  `localStorage` ของเบราว์เซอร์เครื่องนั้น และส่งตรงถึง `api.github.com`
  แนะนำ fine-grained token สิทธิ์ **Contents: Read and write** เฉพาะ repo เดียว
  (โหมด gist ใช้ classic token สิทธิ์ **gist**)

## นำเข้าข้อสอบจากไฟล์ต้นฉบับ

ไฟล์ `.docx` ในไดรฟ์มีข้อความสมบูรณ์ (ไฟล์ `.pdf` มีเลเยอร์ข้อความเพี้ยนจากฟอนต์ฝัง)
จึงใช้วิธีคัดลอกข้อความจาก DOCX มาวางในระบบ:

1. เปิดไฟล์ `05_พาร์ท1-1_คณิตศาสตร์_100ข้อ.docx` → เลือกทั้งหมด → คัดลอก
2. ในเว็บ: **ชุดสอบ → 3 · นำเข้าข้อสอบจากไฟล์ (DOCX / PDF)** → เลือกพาร์ทปลายทาง → วางข้อความ
3. กด **ตรวจสอบข้อความ** → ดูตัวอย่าง/จำนวนข้อ → **บันทึก … ข้อเข้าคลัง**
4. ข้อสอบที่นำเข้าจะถูกรวมเข้าคลังพาร์ทนั้นทันที (ตัดข้อซ้ำอัตโนมัติ) และถูกสำรองขึ้น GitHub ด้วย

ระบบแยกข้อมูลอัตโนมัติจากรูปแบบ `ข้อ N. …` / ตัวเลือก `1) 2) 3) 4)` หรือ `ก. ข. ค. ง.` /
หัวข้อ `วิชา › หัวข้อ` / ตาราง `เฉลย` ท้ายไฟล์ (รองรับคำอธิบายต่อท้ายเฉลย)
