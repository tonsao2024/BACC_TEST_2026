# BACC Exam 2569 — เว็บไซต์ทดสอบออนไลน์ ธ.ก.ส.

เว็บแอปภาษาไทยสำหรับ **ฝึกทำข้อสอบพนักงานการเงิน ระดับ 4 ธ.ก.ส. ปีบัญชี 2569**
แยกตามพาร์ท ออกแบบสไตล์แอปสอบออนไลน์บนมือถือ พร้อมแอนิเมชัน
ดาวน์โหลดผลการทดสอบเป็น PDF และดาวน์โหลดข้อสอบต้นฉบับจาก Google Drive ได้ในตัว

## คุณสมบัติ

- **11 พาร์ทสอบ + Mock Exam** — 1.1 คณิตศาสตร์ · 1.2 วิเคราะห์และเหตุผล · 1.3 ภาษาไทย ·
  1.4 มิติสัมพันธ์ · 1.5 ภาษาอังกฤษ · 2 ความละเอียดแม่นยำ · 3.1 หลักการบัญชี ·
  3.2 การเงินการธนาคาร · 3.3 เศรษฐศาสตร์ · 3.4 สินเชื่อและพัฒนาชนบท · 3.5 การตลาด
- **หน้าทำข้อสอบ** จับเวลาถอยหลัง ส่งอัตโนมัติเมื่อหมดเวลา ปักธงข้อที่สงสัย
  และแผงรายการข้อสอบ (question palette)
- **ผลการทดสอบ** วงแหวนคะแนนแบบ animated, สรุปตามหัวข้อ, เฉลยพร้อมคำอธิบายทุกข้อ
- **ดาวน์โหลดผลการทดสอบเป็น PDF** (A4 ภาษาไทย ผ่าน canvas → PDF ที่สร้างเองในเบราว์เซอร์)
  และบันทึกเป็นรูปภาพ PNG
- **ดาวน์โหลดข้อสอบต้นฉบับ** จากโฟลเดอร์ Google Drive ของชุดเอกสารเตรียมสอบ
- ประวัติการทดสอบเก็บใน `localStorage` (ไม่มีการส่งข้อมูลออกจากเครื่อง)
- แอนิเมชัน: blob ลอย, fade-up แบบ stagger, progress ring, shimmer, confetti, bottom sheet

## เริ่มใช้งาน

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # ไฟล์ production ใน dist/
```

## โครงสร้าง

```
src/
  App.jsx               # จัดการ view / routing / bottom nav / toast
  styles.css            # design system ทั้งหมด
  components/
    Home.jsx            # หน้าแรก + รายการพาร์ท
    PartDetail.jsx      # คำชี้แจง + ลิงก์เอกสารต้นฉบับ
    Quiz.jsx            # หน้าทำข้อสอบ + ตัวจับเวลา
    Result.jsx          # ผลคะแนน + เฉลย + ดาวน์โหลด
    History.jsx         # ประวัติผลสอบ
    Sources.jsx         # เอกสารต้นฉบับจาก Google Drive
    ui.jsx, Icons.jsx   # UI primitives / ไอคอน SVG
  data/
    set1.js set2.js set3.js  # คลังข้อสอบ (118 ข้อ)
    index.js                 # metadata พาร์ท + รายการไฟล์ Drive + Mock Exam
  lib/
    pdf.js              # สร้างรายงานผลเป็น PDF (ฝังภาพ JPEG ใน PDF A4)
    storage.js          # localStorage + helper เวลา/วันที่ไทย
test/
  smoke-entry.jsx       # ชุดทดสอบ end-to-end (jsdom): ทำข้อสอบ → ผล → PDF → ประวัติ
```

## แหล่งข้อมูลข้อสอบ

ข้อสอบในระบบเรียบเรียงตามโครงสร้างและหัวข้อของชุดเอกสารเตรียมสอบ ธ.ก.ส. 2569
บน Google Drive (1,100 ข้อ แยก 11 พาร์ท + Mock Exam 230 ข้อ + เฉลย + รายงาน QA)
ลิงก์ดาวน์โหลดไฟล์ต้นฉบับทั้งหมดอยู่ในเมนู **เอกสาร** ของเว็บไซต์
